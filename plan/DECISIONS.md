# Architecture, interfaces and decision rules

## D-001 — Hybrid physically informed engine

Use a per-voice, dual-polarisation inharmonic modal string, contact/pluck excitation, per-string pickup sensing, a small global body/neck resonance stage and a final safety gain. Additive/modal coefficients are precomputed when a voice or construction snapshot changes, never per sample. Noise uses a seeded PRNG. This is synthesis, not playback of reference samples.

Signal order: MIDI/event → articulation/contact excitation → two string polarisations → palm-contact damping → pickup position/aperture/type per string → pickup combination → neck/body response → master gain/safety clip → identical stereo channels.

## D-002 — Construction is not a guitar preset selector

No named-guitar model selector is exposed. Presets are only serialised combinations of the controls below. Material and pickup names describe parameter sets, not claims to reproduce a proprietary instrument.

## D-003 — Public parameter contract

All IDs are stable, host-visible and finite. Floats use the stated units/ranges; invalid state is rejected rather than partially applied.

| ID | Type, range and default | Engine effect |
|---|---|---|
| `scale_length_mm` | float 609.6–673.1, 647.7 | Speaking length, tension and stiffness; pitch remains MIDI-controlled |
| `fret_crown_height_mm` | float 0.7–1.5, 1.1 | Fret termination loss/contact buzz |
| `fret_crown_width_mm` | float 1.8–3.0, 2.4 | Contact area and high-frequency termination loss |
| `neck_material` | choice `maple`, `mahogany`; maple | Neck loss/resonance coefficient set |
| `body_material` | choice `alder`, `ash`, `mahogany`, `basswood`; alder | Bounded body damping/resonance coefficient set |
| `string_material` | choice `nickel`, `steel`; nickel | Density/stiffness set; initial v1 densities may agree, so gauge must remain independently effective |
| `string_gauge_1_in` … `string_gauge_6_in` | floats 0.007–0.070; 0.010, 0.013, 0.017, 0.026, 0.036, 0.046 | Per-string mass, tension, inharmonicity and excitation impedance |
| `tuning_offset_1_semitones` … `_6_` | int −12…12, 0 | Per-string tuning, clamped to MIDI 28–100 |
| `pickup_1_type` … `_3_type` | `single_coil`, `p90`, `humbucker`; same order | Resonance/Q, aperture and noise floor |
| `pickup_1_from_bridge_mm` … `_3_` | floats 5–180; 25, 65, 120 | Modal sensing comb per string |
| `pickup_1_enabled` … `_3_enabled` | bool; true, true, false | Inclusion in combination |
| `pickup_1_phase_inverted` … `_3_` | bool; false | Signed sum before electrical response |
| `pickup_combination` | `parallel`, `series`; parallel | Parallel: normalised signed mean; series: signed sum scaled by 1/N with shared electrical loading |
| `pick_angle_deg` | float −60…60, 15 | Contact duration, attack time and pick-noise share |
| `pick_depth_mm` | float 0–3, 1.2 | Excitation amplitude, attack/contact shape and noise |
| `palm_mute` | float 0–1, 0 | Continuous additional damping and causal low-pass/contact loss |
| `master_gain_db` | float −24…0, −6 | Final gain before safety clip |

The string index is 1 = high E, 6 = low E. MIDI tuning uses 12-TET, A4 = 440 Hz. Standard MIDI notes from high to low are 64, 59, 55, 50, 45, 40. Fret position for fret `n` is `L_n = L_0 / 2^(n/12)`; fret dimensions never change this formula.

## D-004 — Mapping formulas and safe bounds

The executable planning oracle is `research/spikes/model_spike.py`; frozen expected values are generated by `expected_values.py`, not typed by hand.

For string diameter `d` metres, density `ρ`, speaking length `L` metres and fundamental `f0`: `μ = ρπd²/4`, `T = μ(2Lf0)²`. Initial stiffness uses `B = π³Ed⁴/(64TL²)` with `E = 200 GPa`; clamp `B` to 0–0.02 and mode frequencies below 0.45 times sample rate. Wrapped-string v1 uses effective density/stiffness calibration rather than pretending the solid-core equation is exact.

Pluck position is fixed at 18% of speaking length in v1. Mode `m` excitation contains `sin(mπ·0.18)/m^0.45`; pickup at fractional position `p` contains `sin(mπp)`. Position is measured from the bridge and recomputed from the fretted speaking length. Pickup aperture and electrical resonance are applied after sensing.

Pick attack milliseconds: `clamp(5 + 6(1-depth/3) + 12|angle|/60, 2, 30)`. Excitation amplitude includes `(velocity/127)^1.5 × (0.35 + 0.65 depth/3)`. Pick-noise dB: `−38 + 10|angle|/60 − 8 depth/3`. These are calibrated control laws, not universal physical constants.

Palm mute adds `42 × palm_mute^1.4 dB/s` damping and sweeps causal contact cutoff as `18000 × (900/18000)^palm_mute Hz`. At zero the extra stage is exact bypass. At one, pitch remains defined and the tail decays rapidly rather than becoming a click.

Fret height and neck/body material alter bounded termination/body coefficients; their isolated-stage effect must be measurable but output gain-normalised comparisons must not confuse brightness with loudness. Width acts on high-frequency termination only. No coefficient may make a pole radius ≥0.99995 or output non-finite.

## D-005 — Real-time interface

C++ namespace `egb`:

- `ParameterSnapshot`: strongly typed value for every D-003 parameter; `static Result validate(const ParameterSnapshot&)`.
- `Engine`: `prepare(double sampleRate, int maxBlockSize, int voices)`, `setParameters(const ParameterSnapshot&)`, `render(juce::AudioBuffer<float>&, const juce::MidiBuffer&)`, `reset()`.
- `renderEventFile(const EventFile&, const ParameterSnapshot&, double sampleRate)` returns float32 mono PCM plus `RenderMetadata`.
- `RenderMetadata`: UTF-8 JSON with commit, lockfile SHA-256, seed, complete parameters, event-file SHA-256, UTC timestamp, sample rate, unclipped peak and platform.
- State format: JUCE APVTS XML with `schemaVersion=1`; maximum 256 KiB; unknown IDs and non-finite values are errors. Event format: UTF-8 text, maximum 1 MiB/10000 events, `time_seconds note_on|note_off|control midi velocity|value channel`, strictly non-negative finite times.

No audio-thread allocation, locks, logging, file access or coefficient rebuild. UI/host changes enter an atomic snapshot; preparation or a bounded background coefficient builder produces voice-safe tables. Continuous playing controls are smoothed over 20 ms; structural changes crossfade new voices and never retune ringing voices.

## D-006 — Determinism and output safety

Seed is 20261104 unless an event file overrides it. Each voice derives its seed from `(globalSeed, stringIndex, noteCounter)`, not thread scheduling. The renderer never normalises. Master gain and a final `tanh` safety stage live in the production engine; tests print pre-safety and post-safety peaks. Identical inputs/build/platform must produce bit-identical float32 WAV data; cross-platform comparison uses 1e-6 maximum absolute error because transcendental implementations may differ.

## D-007 — Reference separation

P1 single notes are calibration/research material. P2 single notes are held out from coefficient fitting. Techniques, scales, chords and music are articulation/demo references. Blind pairs use held-out material wherever a matching condition exists. No per-note or per-clip corrective constants are allowed.

## D-009 — Blind listening

Build 12 onset-preserving pairs, 1.0 s, −23 dBFS RMS, 10 ms end fade, 24-bit WAV at 44.1 kHz using the canonical script from `qualitycoding/skills`. Base seed 20261104; add the round number after every disclosed round. Pass only at ≤8/12 correct **and** no unresolved demo realism finding. Three rounds maximum.

## D-010 — CI and packaging without release

Use `ubuntu-24.04`, `windows-2025` and `macos-15` with `fail-fast: false`; add `ubuntu-24.04-arm` for engine-only ARM64 coverage and Alpine 3.22 for a headless libc-variant build. Build VST3 on the three desktop targets. No upload to a release, signing or installation into system plug-in directories. CI artefacts are workflow-run artefacts, not public releases.

## D-011 — Mutation testing opt-out

Omit `S-MUTATE`: the DSP suite depends on analytic signals, reference metrics and human listening, and no C++ mutation setup has been priced against this new project. Reviews must name surviving test gaps instead. This is not a claim that mutation tools are unavailable.

## D-012 — Decision rules

- If a reference archive checksum/licence differs, halt that reference path and write `BLOCKED.md`; never substitute an unlicensed clip.
- If P2 distribution shifts the frozen metric, report the shift; do not retune to P2 or edit the frozen threshold. Continue only through a formal test challenge/amendment.
- If the architecture misses a frozen metric, diagnose onset, harmonic decay, pickup and body stages in that order; make one general mechanism change per iteration, then rerun all tests.
- If performance misses A-009, reduce maximum active modal count using the documented highest-frequency-first rule while preserving at least 12 modes and pitch accuracy; if still missed, halt `BLOCKED.md`. Never loosen the target unilaterally.
- If a vulnerability scan reports Critical/High in a shipped dependency, pin to a verified fixed version through the deviation/amendment process or halt; never suppress the report.
- If pluginval or sanitizer fails, fix the engine and rerun; do not exclude the failing host behaviour.
- If an API differs from D-005, halt on public-interface change; internal implementation may choose the most reversible alternative and log `DEVIATIONS.md`.
- Default: choose the most reversible scope-neutral option and log it, except frozen tests, security, data integrity, public interfaces or research integrity, which require `BLOCKED.md`.

## D-013 — Closed v1 coefficient and allocation contract

The following values remove implementation discretion; they are calibrated v1 coefficients, not claims of universal material physics. Density is 7850 kg/m³ for nickel and steel. `(neck_loss, neck_res)` is maple `(0.8,1.0)`, mahogany `(1.2,0.85)`; `(body_loss, body_res)` is alder `(1.0,1.0)`, ash `(0.75,1.15)`, mahogany `(1.2,0.85)`, basswood `(1.35,0.8)`. Pickup `(resonance_hz,Q,aperture_m)` is single_coil `(3500,2.8,0.018)`, p90 `(2900,2.4,0.022)`, humbucker `(2400,2.0,0.028)`.

Baseline termination loss is `clamp(0.0005 + 0.0004 fret_height_mm + 0.0002 neck_loss,0,0.01)`. Fret width adds a high-frequency-only loss multiplier `clamp(1+0.2(width_mm-2.4),0.76,1.24)`, interpolated linearly from 0 at 1 kHz to full at 8 kHz. Body loss scales resonance decay by `body_loss`; body resonance gain scales by `body_res`. Baseline unmuted mode decay is `0.8+0.025m` dB/s before termination/material/palm terms. Use at most 120 modes and at least 12 where physically available; discard modes at or above `0.45 sample_rate`, highest frequency first. Neither pole radius may reach 0.99995.

For an event on channel 1–6, use that string. For channel-independent host MIDI, choose the highest-pitched string whose tuned open note is no greater than the played note and whose resulting fret is ≤24; if none qualifies, reject the note without allocating a voice. Fret `n = played_midi - (open_midi + tuning_offset)`. Voice stealing, only at the 16-voice cap, selects the oldest releasing voice, otherwise the oldest voice, with a 5 ms equal-power crossfade; ties use lowest string index then lowest note counter.

Enabled parallel pickup output is the signed mean. Series output is the signed sum divided by enabled count, with resonance frequency multiplied by `1/sqrt(N)` and Q multiplied by `sqrt(N)` for N enabled pickups. Reject a snapshot with zero enabled pickups only when rendering is requested; validation preserves the snapshot and the engine emits silence with an explicit status. A global 21-band response may be fitted once on P1 and applied identically to all notes; per-note correction remains forbidden.
